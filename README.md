# credit-lending-portfolio-analysis

This project builds a Python framework to analyse loan‑level performance, estimate credit losses, and evaluate pricing adequacy for a consumer lending portfolio. It mirrors the analytical challenges faced by digital lenders, including PD/LGD modelling, expected loss estimation, and stress testing.

## Objectives

- Model probability of default (PD) using logistic regression and gradient boosting.
- Estimate loss given default (LGD) using recovery data.
- Compute expected loss (EL) and compare it with pricing and costs.
- Analyse portfolio performance by cohort, risk tier, and economic regime.
- Run stress tests to assess resilience under adverse scenarios.
